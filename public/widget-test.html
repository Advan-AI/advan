Advan Widget — Integration Test

This is a static test page that embeds the Advan Chat Widget. The floating chat bubble appears in the bottom-right corner. Click it to open the panel and verify the full embed flow.

Prerequisites

  1. Start the dev server: npm run dev:all (Next.js on :3000, Socket.IO on :3002)
  2. Ensure a row exists in widget_configs with:
    • widgetKey matching the data-key below
    • allowedOrigins containing "http://localhost:3000"
  3. Seed the DB if needed: 
    INSERT INTO widget_configs (id, org_id, widget_key, allowed_origins, pre_chat_form_enabled)
SELECT gen_random_uuid(), id, 'wk_test_local',
       '["http://localhost:3000"]'::jsonb, true
FROM organizations LIMIT 1;
  4. Open this page at http://localhost:3000/widget-test.html and click the chat bubble.

What to verify

  1. Bubble renders bottom-right; click opens animated panel.
  2. Widget frame loads inside the iframe — check browser DevTools Network tab for /api/chat/availability.
  3. If no agents are online, the pre-chat form (name + email) appears; submitting it returns the "Message sent!" confirmation.
  4. If an agent is online, the chat composer appears directly; sending a message calls /api/chat/intake and socket events flow.
  5. Socket connection: DevTools → Network → WS should show a connection to localhost:3002/chat-widget.
  6. Typing indicator: from the dashboard, emit agent:typing:start to see the animated dots in the widget.
  7. Close button (inside the widget) fires a postMessage to the parent, collapsing the panel.
  8. Escape key on the parent page also closes the panel.

Embed snippet (copy this to any page)

<script
  src="http://localhost:3000/widget.js"
  data-key="wk_test_local"
></script>

Replace http://localhost:3000 with your production URL and wk_test_local with your real widget key.
